ASTRO PLAY - NASA Space Apps Challenge 2026

HOW TO PLAY
  Windows : unzip the whole folder, then double-click AstroPlay.exe
            (if Windows SmartScreen appears: "More info" -> "Run anyway")
  Linux   : extract the folder, then run ./AstroPlay

  No Python or installation needed. Keep the "_internal" folder next to the game.

AI SPACE ASSISTANT (optional)
  The assistant works offline from built-in notes. For live Gemini answers, create a file named ".env"
  next to AstroPlay(.exe) containing one line:
      GEMINI_API_KEY=your-own-key
  Get a free key at https://aistudio.google.com/apikey

SAVED GAMES AND SETTINGS
  Windows : %LOCALAPPDATA%\AstroPlay
  Linux   : ~/.local/share/astro-play
